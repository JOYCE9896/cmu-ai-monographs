CMU AI 课程

卡内基梅隆大学前沿 AI 课程研读笔记

整理：Joyce（@JOYCE9896）

课程概览

这里收录卡内基梅隆大学 AI 课程的研读笔记，目前有三门：2026 年春季的 11-711 Advanced NLP，2025 年秋季的 11-664/763 语言模型推理算法，以及 2026 年秋季正在进行的 11-768 AI Agents。笔记根据课程公开的幻灯片和录像整理，按由浅到深的顺序补充背景知识。姊妹项目：Stanford AI 课程。

Technical

11-711: Advanced NLP

Sean Welleck 主讲的 2026 年春季版本，23 讲全部整理完。从文本表示、语言模型和 Transformer 讲起，经过预训练与缩放定律、微调与解码、检索增强、多模态（视觉理解、图像 token、扩散与流），再到评估与实验设计、强化学习与 RLHF、语言模型 Agent，最后几讲讲效率与规模化：量化、并行训练、混合专家、长序列建模和推理时扩展。

11-664/763: Inference Algorithms for Language Modeling

Graham Neubig 与 Amanda Bertsch 2025 年秋季合讲，整理了有公开录像或幻灯片的 15 讲。只讲推理不讲训练：采样方法、束搜索与 A*、约束解码与 JSON 模式、思维链与自洽性、自我修正、推理模型与 GRPO、工具调用与 MCP、Agent、奖励模型与 Best-of-N、最小贝叶斯风险、推理时扩展与模型规模的权衡，以及用蒸馏和缩短推理链降低 token 成本。

11-768: AI Agents

由 Graham Neubig 与 Daniel Fried 主讲，课程进行中，目前整理了 11 讲笔记。讲的是怎样构建、评估和训练基于大语言模型的 Agent：工具调用与约束解码、MCP、长上下文与上下文压缩、技能与记忆、规划与多 Agent 协作，编程 Agent 与电脑操作 Agent 两个应用领域，Agent 的监督微调，从 REINFORCE、GRPO 到 PPO、DAPO 的强化学习算法，以及深度研究 Agent 的评估、训练与检索。后续还有 RL 系统、沙盒与安全、OpenHands 与 LangGraph 框架、人机交互和搜索等主题。

排版原则

  • 少即是多：只保留清晰的小标题、自然段落与必要的简明列表，去掉多余的装饰性边框、背景色块与高频加粗。
  • 字体统一：英文统一使用 Source Serif 4，中文统一使用思源宋体（Noto Serif SC）。代码块、正文、表格与注释使用完全一致的字体，不混用无衬线体或等宽字体。
  • 字号精简：全网页只保留 2 种字号（标题 1.35rem，所有其他正文、代码、表格、注释均为 1.05rem）。
  • 术语自然：Agent、Harness、SFT、RL、Benchmark 等技术专有名词保留英文原生称谓，不作生硬直译。
